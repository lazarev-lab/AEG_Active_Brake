# ⚡ AEG Active Brake & Electronic Trigger (MOSFET)

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![KiCad](https://img.shields.io/badge/KiCad-10-blue.svg)](https://kicad.org)

A compact high-performance MOSFET module for Airsoft Electric Guns (AEGs).

The design replaces traditional mechanical trigger contacts with an electronic switching system based on a half-bridge MOSFET driver, improving trigger response, reducing contact wear, and providing active motor braking to minimize overspin.

---

## ✨ Features

### ⚡ Electronic Trigger Switching

Mechanical trigger contacts carry only a low-current control signal while all motor current flows through dedicated power MOSFETs.

**Benefits:**

* Faster trigger response
* No contact arcing
* Increased trigger lifespan
* Lower electrical losses

---

### 🛑 Active Braking

Upon trigger release, the half-bridge actively drives the motor terminals toward the supply rail, rapidly dissipating the motor's rotational energy.

This significantly reduces gearbox overspin and helps prevent unintended double-shots, especially in high-speed builds.

---

### 🔒 Hardware Shoot-Through Protection

The design uses the `LM5106MM` half-bridge gate driver with a fixed **600 ns dead time**.

This hardware-enforced delay guarantees that the high-side and low-side MOSFETs cannot switch simultaneously.

**Benefits:**

* Prevents shoot-through currents
* Protects MOSFETs from failure
* Improves overall reliability

---

### 🛡️ Transient Protection

The circuit includes dedicated protection against voltage spikes generated by the motor.

| Component | Function                                                                         |
| --------- | -------------------------------------------------------------------------------- |
| `SMBJ18A` | Clamps supply voltage transients during switching and braking                    |
| `SS34`    | Provides an additional low-loss current path and suppresses inductive transients |

---

### 📶 Noise-Resistant Trigger Input

The trigger input uses an active-low configuration with a pull-up resistor.

This helps prevent accidental firing caused by:

* Electrostatic discharge (ESD)
* Electromagnetic interference (EMI)
* Floating trigger contacts

---

## ⚙️ Operating Principle

The trigger controls the `HB` input of the `LM5106MM`.

### Trigger Pressed

* `HB = LOW`
* High-side MOSFET OFF
* Low-side MOSFET ON
* Motor energized

### Trigger Released

* `HB = HIGH`
* High-side MOSFET ON
* Low-side MOSFET OFF
* Active braking engaged

The gate driver automatically inserts a fixed 600 ns dead time during every switching transition.

## 📊 Technical Specifications

| Parameter         | Value                        |
| ----------------- | ---------------------------- |
| Operating Voltage | 7.4 V – 14.8 V Li-Po (2S–4S) |
| Gate Driver       | `LM5106MM`                   |
| Dead Time         | 600 ns                       |
| Power MOSFETs     | 2 × `GT007N04TL`             |
| TVS Diode         | `SMBJ18A`                    |
| Schottky Diode    | `SS34`                       |
| Trigger Type      | Dry Contact / Microswitch    |
| Active Brake      | Yes                          |

## 🔌 Wiring

| Pad         | Connection            |
| ----------- | --------------------- |
| **+Bat**    | Battery Positive (+)  |
| **-Bat**    | Battery Negative (-)  |
| **+Motor**  | Motor Positive (+)    |
| **-Motor**  | Motor Negative (-)    |
| **Buton**   | Trigger Contact       |
| **Buton_2** | Trigger Contact (GND) |

### Trigger Wiring

The trigger simply shorts `Buton` to `Buton_2` when pressed.

---

## ⚠️ Important Notes

### Reverse Polarity

This design does **not** include reverse-polarity protection.

Connecting the battery backwards may permanently damage:

* TVS diode
* Gate driver
* MOSFETs

Always verify wiring before connecting a battery.

### Recommended Batteries

* 2S Li-Po (7.4 V)
* 3S Li-Po (11.1 V)
* 4S Li-Po (14.8 V)
